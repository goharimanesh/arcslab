# ARCSLAB Website

**Advanced Robotics and Control Systems Laboratory**
Department of Mechanical Engineering, University of Torbat Heydarieh, Iran
Founder & director: **Dr. Masoud Goharimanesh** · Co-founder: **Dr. Ali Koochi**

Live site: <https://goharimanesh.github.io/arcslab/>

A fast website made only of HTML, CSS and plain JavaScript (no frameworks, no build step).
Everything that changes — people, projects, publications, courses, equipment, benefactors, news —
lives in **CSV files** in `data/`. Edit a CSV, commit, and the site updates.

| Page | What it shows |
|---|---|
| `index.html` | Interactive continuum robot, About, People, Projects, Publications summary, Teaching (+ Aparat video academy), Facilities, Collaborations, With Gratitude, News, Contact |
| `publications.html` | All papers: search, filters (category / year / type), sorting, per-author statistics, two charts, most-cited list, copy APA/BibTeX, abstracts, QR codes |
| `profile.html?id=…` | One profile page for every member (bio, research, skills, links, projects, publications) |

## 2. Publishing on GitHub Pages (first time)

1. Repository: <https://github.com/goharimanesh/arcslab> (public).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `(root)` → Save.**
3. **Settings → Actions → General → Workflow permissions → “Read and write permissions” → Save.**
   (This lets the weekly job commit the updated publication list.)
4. Optional: **Settings → Secrets and variables → Actions → New secret** `OPENALEX_MAILTO` = an e-mail address.
   OpenAlex then serves the job faster ("polite pool"). The address is not published.
5. Open **Actions → Update publications → Run workflow** once to check everything works.

### Uploading this version
**With Git (recommended — also removes the files that were deleted):**
```bash
git clone https://github.com/goharimanesh/arcslab.git
# copy the new files over the clone, then:
git add -A
git commit -m "Publications page, profiles, interactive robot, teaching, gratitude"
git push
```
**With the GitHub web page:** *Add file → Upload files*, drag all files and folders, commit.
The web upload does **not delete** old files — remove these by hand (open → ⋯ → Delete):
`people/students/bsc-1403-Hosseini/` and the sample projects `projects/tendon-continuum-arm/`,
`projects/soft-gripper/`, `projects/soft-actuator-sim/`, `projects/aerial-continuum/`.
Hidden files to include: `.nojekyll`, `.gitattributes`, `.github/`.

### Preview on your computer
Browsers do not read CSV files from a page opened by double-click. Start a small server:
```bash
cd arcslab
python -m http.server 8000      # then open http://localhost:8000
```

## 3. Editing content (no programming)

On GitHub: open a CSV → ✏️ → edit → **Commit changes**. The site updates in about a minute.

**CSV rules:** never change the first line (column names) · put text that contains commas in "double quotes" ·
separate list items with `;` · leave a cell empty to hide it · a line starting with `#` is ignored ·
in Excel use *Save as → CSV UTF-8*.

### People — `data/team.csv`
| Column | Meaning |
|---|---|
| `id` | unique id = folder name, e.g. `msc-1404-Azadi` |
| `category` | `faculty`, `phd`, `msc`, `bsc` or `alumni` |
| `photo` | `people/students/<id>/photo.jpg` — if the .jpg is missing, `photo.svg` from the same folder is shown |
| `bio`, `research_topic`, `interests`, `skills` | text shown on the card and profile (`;` between items) |
| `pub_names` | how the person is written in papers, e.g. `Goharimanesh M.; Gohari-Manesh M.` — the publication list then **links that name to the profile**. Fill for students only when they have a paper and check the surname + initial does not belong to someone else (e.g. “Kazemi A.” also matches “Kazemi A.S.”). |
| `scholar`, `scopus`, `orcid`, `researchgate`, `linkedin`, `github`, `aparat`, `website`, `cv` | full links → buttons |

**Replace a placeholder photo:** put `photo.jpg` (square, ≥ 400 px) in the person's folder. Nothing else to change.
**New student:** copy `people/students/_TEMPLATE_student/`, rename, add a row to `team.csv` (and a project to `projects.csv` with `student_id`).
**Graduation:** change `category` to `alumni`.

### Projects — `data/projects.csv`
`id, title, status (ongoing/completed/planned), kind (MSc thesis / BSc project / External project / Research), summary, student, student_id, supervisor, keywords, image, start, link`
`student_id` links the project to the student's profile.

### Teaching — `data/courses.csv`
`id, title, title_fa, level, instructor, description, link, kind`. The picture is `assets/images/teaching/<id>.svg`.
Fill `link` with the course-hub address — courses without a link show “Hub link coming soon”.

### Others
- `facilities.csv` — `name, category, description, image`
- `collaborations.csv` — `match_author` (e.g. `Janabi-Sharifi F.`) counts the joint papers automatically
- `benefactors.csv` — `in_memoriam` = `yes` shows “In loving memory”
- `events.csv` — dates `YYYY-MM-DD`; upcoming / past are sorted automatically

## 4. Publications

### How it works
```
Scopus / BibTeX export ─┐
                        ├─► scripts/publications.py ─► data/publications.csv ─► publications.html
OpenAlex (weekly) ──────┘        │  merges duplicates (DOI or similar title)
                                 │  keeps the highest citation count (Scopus / OpenAlex)
                                 └─ assigns ONE main category from data/publication_categories.csv
                                    (data/publication_overrides.csv always wins)
```

### Commands (Python 3.8+, nothing to install)
```bash
python scripts/publications.py probe       # which sources answer right now (OpenAlex, Crossref, ORCID, Semantic Scholar, Scholar)
python scripts/publications.py import data/imports/scopus-goharimanesh.csv data/imports/scopus-koochi.csv
python scripts/publications.py import my-papers.bib        # BibTeX also works
python scripts/publications.py sync        # new papers + citation counts from OpenAlex
python scripts/publications.py classify    # re-apply category rules and overrides
python scripts/publications.py dedupe      # merge duplicates again
python scripts/publications.py stats       # papers, citations, h-index per author
```

### Automatic weekly update
`.github/workflows/update-publications.yml` runs every **Monday 02:17 UTC** (and whenever
`publication_categories.csv`, `publication_overrides.csv`, `publications_config.json` or `data/imports/` change, or when you
press *Run workflow*). It runs `probe → sync → classify` and commits `data/publications.csv` only if something changed.

### Manual update on Windows — `sync.bat`
Double-click `sync.bat` in your local clone. It runs
`git pull --rebase --autostash` → `probe` → `sync` → `classify` → commit → `git push`.
Needs [Git for Windows](https://git-scm.com/download/win) and [Python 3](https://www.python.org/downloads/) (“Add to PATH”).

### Categories — `data/publication_categories.csv`
Each paper gets exactly one main category. Keywords are matched in the **title (×3)**, **keywords (×2)** and **abstract (×1)**;
`term*4` gives a keyword weight 4. The highest score wins; ties go to the smaller `priority`; scores below 3 → `other`.
Current categories (from your actual papers): Continuum & Soft Robotics · MEMS/NEMS & Nanomechanics · Vehicle & Mobility Dynamics ·
Intelligent & Robust Control · AI & Machine Learning in Engineering · Micro/Nanofluids & Heat Transfer · Energy, Environment & Agriculture ·
Biomedical Engineering · Solid Mechanics & Structures · Design Optimization & DoE · Interdisciplinary.
Change words or weights, commit — the workflow re-classifies automatically.

### Corrections — `data/publication_overrides.csv`
`key,category,type,image,hide,note` — `key` is the DOI or the paper `id`. Examples:
```
10.56578/jemse020201,other,,,,management paper
goharimanesh2020fuzzy,,,assets/images/publications/papers/frl-robot.jpg,,own figure
10.1000/wrong.paper,,,,yes,not my paper
```

### Adding a new paper by hand
Easiest: export it from Scopus (CSV) or Google Scholar (BibTeX), put the file in `data/imports/`, commit.
Or run `python scripts/publications.py import file.bib`.

### Notes
- Google Scholar has no API and blocks scripts, so it is not used by `sync`; OpenAlex covers the same papers and is free.
- Citation counts differ between databases; the site shows the highest one. Weekly sync can also add papers that OpenAlex attributes to
  your ORCID — check new ones and hide wrong ones with an override (`hide = yes`).
- “Citations per year” uses OpenAlex’s yearly counts once the first sync has run; before that it shows citations by publication year.

## 5. Customising
- **Colours:** top of `css/style.css` (`--accent` blue, `--olive`).
- **Bold name on the publications page:** `CONFIG.me` at the top of `js/publications.js`.
- **Robot simulator:** block `P` at the top of `js/robot.js` (section length, curvature & speed limits, path size).
- **Texts** (Vision, Mission, Contact): directly in `index.html`, each section is marked with a comment.
